A code wiki for this repository: the LangSmith SDKs (Python and JavaScript). Prioritize a concise quickstart, architecture, key workflows, domain concepts, operations, testing, and integration points. Keep pages grounded in the source and recent changes, and prefer practical navigation for engineers over generic summaries.

Tracing ingestion is the SDKs' core job, so treat each ingestion path as first-class: direct `/runs` writes; the batched `/runs/batch` and `/runs/multipart` queue paths; zstd-compressed multipart; the `otel` and `hybrid` tracing modes; and the OpenTelemetry span-processor route (`python/langsmith/integrations/otel/`, `js/src/experimental/otel/`), which bypasses the batch queue entirely and exports to LangSmith's own `/otel/v1/traces` endpoint. For each path, name the endpoint it hits and the thread that does the I/O.
